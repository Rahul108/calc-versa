# Module Documentation: Analysis Service (Python)

## Path
`backend/analysis-service-python/`

## Tech Stack
- **Language**: Python 3.10+
- **Container**: `infra/docker/analysis-service-python.Dockerfile`

---

## Core Responsibilities
1. **Statistical Data Processing**: Runs complex statistical algorithms, regression models, and data analytics on datasets generated by calculation tools.
2. **Batch Processing**: Consumes background calculation job events published via RabbitMQ (`infra/rabbitmq/`).
3. **Report Generation**: Exports calculated outputs to PDF, CSV, or visual report metrics.
