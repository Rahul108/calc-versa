# CalcVersa React SPA Frontend

This directory contains the React SPA application built with Vite and Nx.

## Available Routes
- Tools Dashboard: `http://localhost:4200/`
- Dynamic Tool Runner: `http://localhost:4200/product?id=<id>`
- AI Prompt Copilot: `http://localhost:4200/ai-copilot`
- Creative Tool Builder: `http://localhost:4200/create`
- User Login: `http://localhost:4200/login`
